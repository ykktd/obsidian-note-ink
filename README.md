# Note Ink — 手書き・PDF注釈

iPadのObsidianで、PDF資料やMarkdownノートにペン・蛍光ペンで書き込み、日本語UIで読書・学習・仕事に使うための個人向けプラグインです。GitHub上では、元リポジトリから独立した公開プロジェクトとして管理しています。

[Mobile Ink Annotation](https://github.com/jepicaju862-lab/mobile-ink-annotation) の公開Basic版（upstream commit `ac4f810fe767e44a5a7adf4303a1ad74566b1165`）から派生しています。元作者はpeyote / jepicaju862-labです。有料Pro版のコード・配布物は使用していません。

改変開始日：2026年10月9日。1.3.0ではPDF表示をObsidian標準ビューアへ移し、ページ単位で注釈を重ねる方式に変更しました（2026年10月10日）。日本語化、PDF書き出し、保存と入力サイズの保護を追加しています。GitHub上の独立化後も、派生元のGPL-3.0-or-laterと作者表記を引き継ぎます。

## できること

- iPad / Apple Pencil向けの手書き、蛍光ペン、消しゴムと自動保存（上流の機能）。
- ペンで書き、指でページを移動。文字のハイライト・下線・取り消し線・コメント。
- 操作ラベル、設定、メッセージ、ページ移動を日本語化。
- **書き込み入りPDFを別ファイルに保存**（Note Inkで独自実装）。
- PDFへの書き出しにネット接続、アカウント、外部サービスは不要。

## iPadへの導入（BRAT）

1. Obsidianの「設定 → コミュニティプラグイン → 閲覧」で **BRAT** を検索し、インストールして有効にします。
2. コマンドパレットの **BRAT: Add a beta plugin for testing** を実行し、`https://github.com/ykktd/obsidian-note-ink` を入力します。
3. 公開済みの最新リリースを選んで追加します。
4. コミュニティプラグイン一覧で **Note Ink（手書き・PDF注釈）** を有効にします。
5. PDF資料をVaultに入れて開き、コマンドパレットで **現在のファイルに手書き注釈を付ける** を実行します。
6. 設定の **PDFを注釈画面で開く** をオンにすると、以後はPDFをタップするだけでこの画面が開きます。

名称変更後も内部のプラグインIDは `obsidian-lecture-ink` のままです。既存の注釈・設定を引き継ぐため、保存フォルダや登録画面の識別子は変更していません。

元のMobile Ink Annotationと同じPDFに同時に書き込むのは避けてください。Note Inkは別のプラグインID・画面・データ保存先を使います。

## 1.3.2のPDF表示と操作

- PDFの読み込み、スクロール、ページ移動、検索、ズームはObsidian標準ビューアが担当します。そのページに注釈を重ねます。独自ビューアで同じPDFをもう一度描画する処理は使いません。
- 保存済みの注釈を描くのは画面付近のページだけです。表示用の筆跡画像は1ページ100万画素を上限にし、スクロールやズームだけでは全筆跡を描き直しません。大きく拡大すると画像の粗さが見えることがあります。
- 書き込むページにだけ入力用の筆跡層を置き、スクロールで不要になった層は解放します。入力用は各層200万画素を上限にします。
- ペン・蛍光ペン・消しゴム・閲覧／文字選択・色・太さ・取り消し／やり直し・保存を移動できるツールバーに表示します。消しゴムを再度押すと直前のペンまたは蛍光ペンに戻ります。
- バー左端のつまみをドラッグすると、見切れない範囲で自由に移動できます。右端の「−」で最小化し、残った丸いボタンを押すと戻ります。最小化中のボタンも移動できます。
- 消しゴムの選択欄は消しゴムボタンの下または上に表示します。バーの位置と空き領域に応じて向きを切り替え、画面端では選択欄の位置だけを調整します。画面サイズが変わると、バーも見切れない位置へ収まります。
- 指の移動は標準ビューアへ渡します。ペンを離した後に指スクロールを一定時間止める処理を廃止しました。文字注釈は「閲覧・文字選択」で文字を選び、右クリック／長押しメニューから追加します。
- ペン・蛍光ペン・消しゴムの太さはスライダーで変更します。アイコンは24px、ボタンは44pxです。
- 消しゴムは「部分消去」「ストローク消去」を選べます。部分消去は通った範囲だけを消し、元の線の形・太さと新しく重ねた筆跡を保ちます。範囲は細い灰色の円で表示します。
- 一時消しゴムを削除しました。約800ms後の自動保存、保存失敗時の再試行、書き込み入りPDFへの書き出しを引き継ぎます。
- 保存済みの線をページ直下のHTMLキャンバスに描き、入力時と同じ配置方式に統一しました。SVG foreignObject内のキャンバスに起因するWebKitの表示ズレを回避します。
- 右上の「注釈を閉じる」で保存して注釈層を外せます。同じPDFは一つのタブで編集し、他のタブは通常表示になります。
- Apple Pencil本体のダブルタップは未対応です。Markdownと単独手書きノートの表示・保存方式は従来のままです。

## Markdown・単独手書きノートの操作と描画

- ペン・蛍光ペン・消しゴム・色・太さ・文字選択・取り消し／やり直しを注釈ツールバーに表示します。同じペンを再度押しても閲覧モードへ切り替わりません。
- ツールバーの消しゴムを再度押すと、直前のペンまたは蛍光ペンへ戻ります。色と太さは保持します。取り消しは一筆、消しゴムは一度の操作を単位とします。
- 横三点メニュー、保存ボタン、ズームボタンは注釈画面から外しました。指で移動し、二本指で拡大・縮小できます。Obsidian標準のPDF画面のメニューは維持します。
- 注釈は操作が止まってから約800ms後に自動保存します。書き込み中は新しい保存を開始しません。保存失敗時は筆跡を保持し、画面下の「再試行」で再保存できます。
- 右上の **元のPDFに戻る** は、最新の筆跡を保存してから、そのタブを元のPDF表示に切り替えます。注釈は非表示になりますが、注釈画面を再度開けば続きから編集できます。他のタブは閉じません。
- 曲線を中点で補間し、入力を画面の更新タイミングに合わせて描画します。線幅の計算は追加された点だけで行い、一筆書くたびに文書全体を再描画する処理を廃止しました。
- iPadの筆跡層は実効表示倍率3、各層400万画素、表示中の全筆跡層1600万画素を上限とします。高倍率では画質をこの上限に合わせます。
- Apple Pencil本体のダブルタップは未対応です。ツールバーボタンで切り替えます。

1.3.2はツールバーの移動・最小化と消しゴム選択欄の配置を改善したリリースです。BRATで更新できます。iPad実機での確認は公開後に行います。配布物を手動導入する場合はVaultの `.obsidian/plugins/obsidian-lecture-ink/` の `main.js`, `manifest.json`, `styles.css` だけを上書きし、既存の `annotations/` と `data.json` は残してください。

部分消去の範囲はv2の各筆跡に追加情報として保存します。1.3.0以前はこの情報を描画しないため、部分消去したデータを旧版で開くと消去前の線が見えます。部分消去を使ったPDFの編集は1.3.1以降で行ってください。書き出したPDFには消去結果が反映され、通常のPDFビューアで表示できます。

検証コマンド: `npm run typecheck`、`npm test`、`npm run build`、`node scripts/alignment-check.mjs`、`node scripts/eraser-test.mjs`、`node scripts/toolbar-test.mjs`、`node scripts/native-pdf-test.mjs`、`node scripts/browser-test.mjs`。ブラウザ検証はローカルのObsidian配布物とChrome／Playwright WebKitを使用します。

## 書き込み入りPDFの保存と共有

1. PDFを注釈画面で開いて書き込みます。
2. 右上の **書き込み入りPDFを書き出す** を選びます（コマンドパレットからも実行できます）。
3. 同じフォルダに `資料-書き込み.pdf` ができます。既にあれば `資料-書き込み-2.pdf` のように番号を付けます。
4. 新しいPDFを開いて内容を確認し、Obsidianまたは「ファイル」アプリの共有操作で送れます。

**元のPDFは変更しません。** 編集用の注釈データも残ります。出力PDFだけで他のPDFビューアーに手書き・ハイライトが表示され、コメントはPDFの標準コメントとして読めます。

元のPDFのページ・文字・埋め込みフォントを保持し、透明な手書き画像をページに重ねます。元の文字は検索・選択できますが、書き出した手書きは画像なので、一筆ごとの編集や検索はできません。編集は元のPDFをこのプラグインで開いて続け、再び別のPDFを書き出してください。別のPDFアプリで元PDFと注釈データを組み直すことはできません。

ページの縦横比が混在するPDFでは、表示用の外側の余白に書いた線は書き出し時に切れます。PDFのページ内に書いてください。

導入方法の参考：[BRAT作者の公式ガイド](https://tfthacker.com/brat-quick-guide)。

## データと既存版からの移行

編集用データはVault内の `.obsidian/plugins/obsidian-lecture-ink/annotations/` に保存されます。PDFだけでなく、このフォルダもバックアップしてください。同期サービスによっては `.obsidian` 内のプラグインデータの同期設定が必要です。

1.3.0のPDF注釈は、**ページ番号＋PDF上の座標（v2）だけ**を保存します。表示時のズームや回転に依存する全ページ通算の座標は保存しません。旧v1の注釈は読み込み時に変換し、初回保存前に元のJSONをそのまま `.v1-<識別値>.bak` へ残します。以後はv2のみで保存し、v1へ戻す変換は行いません。読み取れない筆跡・文字注釈、ページ数の不一致、別画面・端末からの更新を検出した場合は上書きを止めます。

旧版はv2を編集できません。旧版へ戻す場合はObsidianを閉じ、現在の注釈を別途保管してから、対応する `.bak` の内容を元の `.ink.json` に復元してください。移行後に追加した筆跡は旧バックアップに含まれません。Markdownと単独手書きノートはv1のままです。

以前のMobile Ink Annotationに書き込みがある場合：

1. 以前のプラグインで保存し、PDFとVaultをバックアップします。
2. Obsidianを閉じて、以前の `.obsidian/plugins/mobile-ink-annotation-basic/annotations/` のファイルを、新しい `.obsidian/plugins/obsidian-lecture-ink/annotations/` に**コピー**します。元のデータは残します。
3. PDFのファイル名・Vault内の場所は変えずに、Note Inkで開いて内容を確認します。

注釈ファイル名には元PDFのパスから計算した値が含まれるため、元PDFの移動・名前変更で注釈が見えなくなる場合があります。この点は上流と同じです。プラグインを削除する前には注釈データのバックアップと書き込み入りPDFの出力を行ってください。

## 対応範囲と検証上の限界

- PDF注釈層はObsidianの内部ビューア構造を使用します。1.14.4のPDF.js 5.3.34で検証しています。対応する内部構造がない版では注釈を開かず、標準PDF表示を維持します。更新後の互換性確認が必要です。
- PDFの書き出しのみを追加しています。MarkdownノートのPDF化は対象外です。
- 暗号化・パスワード付きPDFはこの版では書き出せません。
- 100MB・1000ページを超えるPDFや極端に縦長のページは、分割して開いてください。ページごとの透明画像は最大400万画素に抑え、順番に処理します。小さいPDFでも大量の書き込みでiPadのメモリが不足する場合があります。
- 電子署名があるPDFの出力コピーでは署名の検証が無効になります。元PDFの署名はそのままです。
- 回転・切り抜き・大きさの異なるページの座標変換、元の文字の保持、日本語コメント、保存先の重複、保存失敗をテスト済みです。
- WebKitのiPad表示相当の検証は実機のObsidian / Apple Pencilの検証を代替しません。まずPDF資料のコピーで書き込み・閉じて再表示・出力を試してください。
- Obsidian本体を隔離コピーで起動する自動検証は、起動待ちで完了できていません。内蔵ビューアを使ったブラウザ検証と区別し、実際のObsidian上での接続・操作確認が必要です。
- 自分で選んで開くVault内のファイルを扱うコミュニティプラグインです。監査は既知の問題やコード上の危険な経路を確認するもので、完全な安全を保証しません。

## 開発・配布

Node.js 20以降で以下を実行します。

```sh
npm ci --ignore-scripts
npm run typecheck
npm test
npm run build
```

大きなPDFの検証は `node scripts/performance-test.mjs after`（50ページ・5,000筆跡）です。旧版との比較は、未変更の1.1.1のチェックアウトを `NOTE_INK_BASELINE_ROOT` に指定して `node scripts/performance-test.mjs before` を実行します。

ブラウザ検証は `node scripts/browser-test.mjs`（WebKitとmacOS版Chromeが必要）です。Obsidian APIのスタブを使ったローカルの画面検証で、実際のVaultにはアクセスしません。

標準PDFビューアへの注釈層の検証は `node scripts/native-pdf-test.mjs` です。ローカルにあるObsidianのPDF.jsを使い、50ページ・5,000筆跡で保存、移行、ズーム・回転、20ページ移動、指スクロール、保存失敗からの回復、書き出しを確認します。macOSでは最新のObsidianのアーカイブを自動検出し、他の環境では `NOTE_INK_OBSIDIAN_ASAR` で指定できます。

配布する `main.js` はこのソースから生成し、GitHub Releaseに `manifest.json`, `main.js`, `styles.css` を添付します。BRATはこの3ファイルを使います。`pdf-lib` はバンドルに含まれ、追加のダウンロードは発生しません。PDF表示のランタイムはObsidianが提供し、日本語PDFなどに必要なCMapと標準フォントの補助データはバンドルに含めています。
